# Essential Core Design Principles

## 1. Quiet hierarchy

Show the most important information first. Use generous spacing, short labels, and a small number of visible actions. Avoid dashboard clutter.

## 2. One system, adaptable expression

Essential apps share tokens, interaction patterns, accessibility rules, and component behavior. Individual products may adapt their layouts to their purpose.

## 3. Color with purpose

The default foundation uses neutral surfaces and a restrained teal accent. Gold is an optional expressive accent for focused or editorial experiences, not a universal requirement.

## 4. Motion that explains

Motion should communicate state changes and spatial relationships. Prefer short, continuous transitions over decorative movement. Respect reduced-motion preferences.

## 5. Glass is a material, not a theme

Use translucent glass only when it improves layering or context. Keep text readable and controls discoverable. Never make every surface translucent.

## 6. Accessibility is part of the component

Components should support keyboard interaction, visible focus, semantic HTML, sufficient contrast, and comfortable touch targets.

## 7. Theme consistency

Support light, dark, and system modes. Components consume semantic variables rather than hard-coded theme colors.
