# Essential Core

**One Core. Infinite Possibilities.**

Essential Core is the shared foundation for the Essential ecosystem by AX. It provides reusable design tokens, UI primitives, motion conventions, and app architecture standards so each Essential product feels consistent without becoming a copy of the same app.

## Goals

- Shared design language across Essential apps
- Reusable, accessible UI components
- Consistent light, dark, and system themes
- Smooth, restrained motion with reduced-motion support
- Framework-independent design tokens
- Clear documentation and starter templates

## Planned structure

```
packages/
  tokens/       Design tokens and theme definitions
  ui-react/     Reusable React components
  motion/       Shared motion primitives and guidelines
apps/
  playground/   Component and theme preview
docs/
  design/       Design principles and usage guidance
```

## Design principles

- Minimal layouts, generous whitespace, clear hierarchy
- AMOLED-friendly dark surfaces with a restrained teal accent
- Light, dark, and system theme support
- Material 3 Expressive-inspired usability, with carefully used Liquid Glass effects
- Accessibility first: keyboard support, contrast, and reduced motion

## Status

Early foundation. APIs and package boundaries may evolve as the system is implemented.
